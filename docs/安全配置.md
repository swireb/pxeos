# 安全配置

## 默认 Root 凭据

三种 filesystem 配置（x64、x86、arm64）均启用了 Root 密码登录；默认账号为 `root`，默认密码为 `pxeos`。修改配置后必须重新构建对应架构的 initramfs：x64 `init.xz`、x86 `init_32.xz`、arm64 `arm_init.cpio.gz` 才会生效。

该密码为所有设备共享的弱默认密码，不应视为加密或安全保护。仅应在隔离的管理网络中使用；在发布或接入生产网络前，必须修改默认密码。

## 敏感信息与运行时边界

网络诊断和任务错误输出必须过滤 token、SMB 密码和凭据文件路径；日志不得输出完整凭据。PXEOS 不直接复制 FOG 运行时脚本或服务端 endpoint，仍使用 RootPXE 的 token、MAC、任务快照与 `attention` 协议。

## HTTP 引导与 HTTPS 控制通信

iPXE 的内核与 initramfs 引导可继续使用 HTTP；PXEOS 启动后保留服务端通过 `web`/`pxeapi` 下发的完整控制 URL，不固化主机名或端口，也不会自行从 HTTPS 降级或回退到 HTTP。RootPXE 控制 URL 为 HTTPS 时，checkin、磁盘许可、进度、阶段、完成、错误重试、初始化和手动多播控制请求使用 `curl -k`；HTTP URL 则保持原有兼容行为。

`-k` 保留 TLS 加密，但不验证证书链、SAN 或服务器身份，存在受控网络内的中间人风险。该例外仅限 PXEOS 到 RootPXE 的控制通信，不得扩展到镜像源、第三方下载或 SSH；token、密码和其他凭据仍不得记录到日志。

与 RootPXE 的磁盘许可、主机名和离线镜像写入边界见[RootPXE 集成](RootPXE集成.md)，失败后的 `attention` 与重试处理见[故障处理](故障处理.md)。
