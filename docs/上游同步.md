# 上游同步

PXEOS 参考 [FOGProject/fos](https://github.com/FOGProject/fos) 的提交进行人工适配，不直接 `cherry-pick` 或覆盖 FOG 运行时脚本。构建、CI 和 Buildroot 包改动可按 PXEOS 自有板级、存储模型、协议及安全边界迁移；运行时修复必须先完成等价适配。
