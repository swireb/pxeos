## 故障处理

- Linux Cloud-init 注入失败依据固定脱敏理由码定位，先检查客户端能力和私有正文校验，再检查镜像准备、目标根、磁盘许可、路径、缓存、seed 和标签工具。注入失败不代表用户配置已执行。
- 网络配置要求新版客户端能力，未填写时两个网络字符串都必须为空，填写时正文与散列必须完整匹配。旧能力、字段部分缺失、错误类型、超出字节上限或散列错误均拒绝，不能回退到旧客户端。
- 网络非空时种子必须恰好三个文件，空网络仍必须恰好两个；清空网络不会删除目标已有的网络文件，已有额外文件、缺失或篡改均按外来种子处理。排查网络问题请核对目标首次开机的原生日志，不改 PXEOS 当前网络或 DHCP。
- 网络配置可能含 Wi-Fi 凭据，不把正文粘贴到错误、任务日志、命令参数或共享诊断文档中。
- 未预装、明确禁用、缓存未清理、未知 seed、已有半份 seed 或不同任务内容应由镜像管理员核对并重新制作干净镜像；PXEOS 不清理未知目标内容。清理失败保留证据，不递归删除或盲覆盖。
- 目标开机执行问题由原生 Cloud-init 状态和日志定位；部署回执只有离线注入结果，不能替代目标首启验证。固定路径与安全边界见 [RootPXE 集成](RootPXE集成.md)。
- PXEOS 的错误处理使用 RootPXE 任务关联与 attention 协议，不调用 FOG endpoint。凭据与日志要求见 [安全配置](安全配置.md)。

```text
cloud_init_not_installed            #缺少可信配置或预装程序
cloud_init_explicitly_disabled      #禁用标志或原生服务被mask
cloud_init_cache_not_clean          #镜像含旧Cloud-init缓存
cloud_init_foreign_seed             #未知seed、额外文件、半份seed或不同任务
cloud_init_target_path_unsafe       #路径、属主、权限或链接不可信
cloud_init_seed_hash_mismatch       #原字节散列读回不匹配
cloud_init_label_tools_missing      #PXEOS本机标签工具缺失
cloud_init_label_unverified         #目标策略或标签读回失败
cloud_init_seed_publish_failed      #本任务期望的两文件或三文件发布失败
cloud_init_seed_rollback_failed     #受控失败回滚未能证明完整清理
cloud_init_mount_cleanup_failed     #本次挂载或卷组清理失败
cloud_init_roots_not_unique         #没有唯一Linux根
cloud_init_disk_permit_invalid      #磁盘许可映射或硬件身份不匹配
```

cloud-init status --long

## Capture/restore 失败传播（2026-08-26）

- 历史说明按 [e261c3b](https://github.com/FOGProject/fos/commit/e261c3b) 的问题模型和 [3b9eaff](https://github.com/FOGProject/fos/commit/3b9eaff) 的失败重试保护人工适配。
- 捕获的压缩与分片后台流水线独立检查失败；产物改名或任务完成前等待对应写入进程。Partclone、压缩器、分片器或存储写入任一失败都进入 attention，不能继续成功回调。
- 还原分别检查镜像读取进程和解压、Partclone 流水线。分片只接受非空、可读的普通文件并保持既有顺序，无匹配或目录在写盘前拒绝；下游命令成功不能掩盖来源失败。
- 完成回调保留失败重试保护，短暂网络失败按既有退避重试；耗尽次数后进入 attention，不会假报成功。

```text
capture                  #捕获流水线失败阶段
RESTORE_SOURCE_FAILED    #镜像来源读取失败
RESTORE_PIPELINE_FAILED  #解压或还原流水线失败
finish_notify            #完成通知重试耗尽阶段
```

## 联调清单与边界

- 上述说明只覆盖受控 mock 回归，不能替代真实设备。必须在可牺牲设备上分别验证 NFS 与 SMB 的磁盘满、断链/权限拒绝、压缩器/Partclone 故障、镜像读取故障，以及完成通知短暂不可达和最终不可达；日志与任务错误不得输出令牌、SMB 密码或完整凭据。
- 还必须联调 GPT/MBR、512e/4Kn、NVMe、Windows 有无应答文件、失败 attention 和重试链路。内核、ARM64 与 Realtek 硬件验证边界见 [硬件兼容性](硬件兼容性.md#构建与回退边界)；严禁在开发机系统盘验证。
